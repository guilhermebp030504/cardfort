# CardFort

E-commerce web application developed to practice CRUD operations, product management, and full-stack application architecture.

Focused on furniture sales simulation with product registration and management features.

---

## Features

- Product CRUD
- Product listing
- Product management
- Responsive web interface
- Database integration
- Backend API communication

---

## Technologies

- Node.js
- JavaScript
- SQL
- HTML
- CSS
- PHP

---

## Goals

The main purpose of this project was to improve backend and database knowledge through a practical e-commerce scenario.

---

## Running the Project

```bash
# Clone repository
git clone https://github.com/guilhermebp030504/cardfort

# Install dependencies
npm install

# Start project
npm start
```
